# xClick

[English](README.md) · **简体中文**

xClick 是一款适用于 Chrome 和 Edge 的 Manifest V3 扩展，为 X 上的点赞、关注、回复和发送操作添加动画和音效。特效在本地运行，音效由浏览器通过 Web Audio API 合成。需要 AI 回复草稿时，可以接入自己的模型厂商或 API 中转服务。

## 安装

1. 下载并解压 [xclick-v0.5.0.zip](https://github.com/mCapricorn/xClick/releases/download/v0.5.0/xclick-v0.5.0.zip)。
2. 在 Chrome 地址栏打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。从源码安装时，选择项目根目录。
4. 刷新已打开的 X 页面。点击浏览器工具栏中的 xClick 图标，即可预览和调整特效。

## 交互特效

| 在 X 上的操作 | 反馈效果 |
| --- | --- |
| 点赞 | 霓虹爱心绽放，伴随点击音效 |
| 关注 | 光环向外扩散，在个人资料页关注时也有提示 |
| 回复 | 扫描线和画面干扰效果，伴随电子音效 |
| 发送评论或帖子 | 独立的绽放动画，伴随两到三个音符组成的上行提示音 |

在扩展弹窗中可以一键开关全部特效，也可以按场景开关动画、选择脉冲或霓虹绽放等样式，或让样式轮换。点击场景预览即可查看动画，开启声音后也能试听。音效有经典、变奏和轮换三种模式，可独立静音或调节音量。

弹窗和 X 页面共用配色，支持赛博霓虹、极光、樱花、单色和随机自定义配色。动画尊重系统的减少动态效果偏好。使用 X 的 `L` 点赞、`R` 回复和 `F` 关注快捷键时，也能看到对应反馈。操作仍由你在 X 上完成。

弹窗和 AI 设置默认跟随浏览器语言。右上角可切换英语、简体中文、繁体中文、德语、意大利语、日语、韩语和法语，浏览器会记住你的选择。

## 使用 AI 回复草稿

v0.5.0 的 AI 功能需要自备 API Token，调用费用由所选厂商或中转服务计收。只使用本地特效时无需配置密钥。

1. 在扩展弹窗中点击「配置模型」，选择厂商、填写 API 密钥，然后选择推荐模型或输入模型 ID，点击「保存」。OpenAI、Claude、Gemini、Grok、DeepSeek、Kimi 和豆包支持从厂商加载模型列表。保存密钥并授权访问后，列表会自动加载。通义千问和智谱 GLM 提供内置推荐。豆包使用火山方舟北京区的 API 密钥，可选择已开通的模型或输入推理接入点 ID（`ep-…`）。
2. 打开 X 的回复框，点击媒体和表情工具末尾的「AI 生成」星光图标。候选草稿会出现在工具栏下方，旁边的滑杆按钮可打开 AI 设置。模型以原帖为主，最多参考同一讨论中已加载的五条评论，并按原帖的主要语言生成英语、简体中文或繁体中文回复。
3. 选中候选即可将原文追加到现有草稿。需要翻译时，在设置中开启「双语辅助（显示母语参考）」，选择母语并保存。译文显示在外语候选下方，供阅读参考。编辑好草稿后，点击 X 的回复按钮发送。

### 回复风格和试写

在「回复风格」中至少勾选一种并保存，每个选中的风格对应一条候选。默认风格为极简、简洁、聊天口吻、生动、热情健谈和真诚友好。也可选择好奇追问、冷幽默、暖心鼓励，或让当前厂商起草一条提及 `@grok`、询问原帖细节的回复。

打开「管理自定义风格」，点击「添加自定义风格」，填写名称和提示词。在「试用回复风格」中输入一条测试语句，或点击「生成随机测试语句」，再选择任意内置或自定义风格并点击「试写此风格」。试写时也能选择尚未勾选的风格，同一句话的多次结果会保留在页面上，方便比较。生成测试语句和试写都会调用当前表单中的模型，可能产生费用。点击「保存」可保留测试语句、风格和勾选项。

### 帖子配图与媒体回复

在高级模型设置中，可为有配图的帖子单独选择同一厂商的视觉模型，共用现有密钥。默认使用回复模型。「发送帖子配图」默认开启，支持的视觉模型最多会收到四张来自原帖或引用帖的 X 图片链接。结果会显示实际发送的图片数。纯文本模型和未识别的模型 ID 只接收文字。视觉模型拒绝图片且原帖有正文时，会用正文重试一次。纯图片帖子需要扩展能识别的视觉模型。

- **OpenAI 生图**。将 OpenAI 的 `gpt-6.2-sol` 保存为默认回复模型后，点击生成配图会调用 Responses API 的 `image_generation` 工具。自定义接口地址也需要支持该工具。
- **豆包配图和 GIF**。在高级模型设置中填写已开通的 Seedream 或 Seedance 模型 ID，即可在候选草稿旁生成配图或 GIF。插入草稿后，媒体按钮仍会显示在回复框下方。缺少配图模型时，可以从配置入口打开 AI 设置。每次生成都会发起一次付费请求，发送所选草稿、原帖正文，并可附上第一张配图。预览文件后可将其添加到回复或下载，GIF 转换在本地完成。

### 中转服务与密钥管理

按中转服务支持的 API 协议选择厂商。例如，兼容 Chat Completions 的中转服务可选择 OpenAI，在「API 基础地址（可选）」中填写 `https://relay.example/v1` 并输入中转密钥。基础地址应包含必要的路径前缀和版本号，扩展会追加 `/chat/completions` 或 `/models` 等操作路径。留空时使用厂商官方接口。使用 HTTP 会明文传输密钥和请求内容，建议使用 HTTPS。

浏览器会分别保存每家厂商的密钥、接口地址和模型。切换厂商可恢复其配置，点击「保存」后用于回复。更换接口地址时，需要为新地址重新输入密钥。点击「清除所有厂商配置」会移除全部已保存的厂商和密钥。

## 隐私与开发

使用 AI 时，所选厂商或中转服务会收到生成所需的帖子内容。密钥保存在当前浏览器中。有关发送的数据和保存的设置，见[隐私政策](PRIVACY_POLICY.md)。

本地检查命令与浏览器测试步骤见[开发指南](docs/DEVELOPMENT.md)。任务分派、提交和 PR 流程见[贡献指南](CONTRIBUTING.md)。项目基线和已验证的环境见[当前状态](docs/status.md)。X 页面结构的变化可能影响按钮识别。
